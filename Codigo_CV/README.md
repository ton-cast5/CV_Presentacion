# CV Miguel de la Cruz Vargas — A4

## Archivos
- `index.html`: versión modular, con CSS y JavaScript separados.
- `styles.css`: diseño y reglas de impresión en A4.
- `script.js`: carga opcional de fotografía e impresión.
- `standalone.html`: versión de un solo archivo.

## Uso
1. Abre `index.html` en Chrome o Edge.
2. Para añadir la foto, coloca una imagen llamada `foto.jpg` en la misma carpeta.
3. Pulsa **Imprimir / Guardar como PDF**.
4. En el diálogo de impresión elige papel **A4**, márgenes **Ninguno** y activa **Gráficos de fondo**. Escala: **100 %** o **Ajustar al área imprimible** si el navegador recorta.

El diseño está configurado a 210 × 297 mm. El PDF de referencia original era tamaño carta; esta reconstrucción se ha adaptado a A4, por lo que las proporciones y algunos saltos de línea pueden diferir ligeramente.
